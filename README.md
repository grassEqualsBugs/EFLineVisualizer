# Electric Field Visualizer

A simple Electric Field Visualizer built using HTML5 Canvas for intuitive, interactive visualization of electric field lines and potentials.

## Overview

This tool helps users explore the behavior of electric fields generated by point charges. It's ideal for students, educators, and anyone interested in electromagnetism. The visualizer allows for placing positive and negative charges on a 2D canvas and dynamically displays field lines in real-time.

## Features

- Add and remove point charges
- Press T at the cursor to release a positive test charge from rest; each press adds another
- Continuous electric field lines by default, with a dropdown to switch to vector arrows
- Intuitive click-and-drag interface
- Accurate vector field calculation
- Lightweight, runs entirely in the browser

Black test charges accelerate independently in the field without affecting the source charges or each other. Each shows an arrow indicating the local electric-field direction and sticks to negative source charges on contact, following them when dragged. Removing a negative source releases its attached test charges. Contact with a positive source still removes the test charge. Uncheck "Move test charges" or press Space with the cursor over the canvas to pause movement while field arrows keep updating. Pausing releases attachments; test charges resume from their current positions. Uncheck "Show test-charge arrows" to hide those arrows independently of movement. E removes the charge under the cursor, and R clears everything.

## Built With

- HTML5 Canvas
- Vanilla JavaScript
- CSS3

Hold I with the cursor over the canvas to trace an integration path. Return near the start to snap it closed. The readout uses the electric potential difference, so a closed path gives zero.
